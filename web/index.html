Cat vs Dog Image Classifier

A deep learning project that classifies an image as cat or dog using transfer learning with MobileNetV2 (TensorFlow/Keras). By Eshal Afzal Sial.

Dataset Details

  • Name: Cat and Dog (by tongpython, Kaggle, secondary dataset)
  • Link: https://www.kaggle.com/datasets/tongpython/cat-and-dog
  • Size: about 10,000 images in two balanced classes
  • Train: 4,000 cats and 4,005 dogs (80% training, 20% validation)
  • Test: 1,011 cats and 1,012 dogs

Model and Code Details

  • Base model: MobileNetV2 pre-trained on ImageNet (frozen)
  • Head: Global Average Pooling, Dropout (0.2), Dense (1, sigmoid)
  • Augmentation: random horizontal flip, rotation, zoom
  • Training: Adam optimizer (learning rate 1e-3), binary cross-entropy loss, input size 224 x 224, batch size 32
  • Code: src/train.py (training), src/predict.py (prediction), src/check_data.py (data check), src/convert_onnx.py (ONNX export for this web demo)
  • Weights: model/cat_dog_model.keras and model/cat_dog.weights.h5 in the GitHub repository
